# Smart Study Planner 

Smart Study Planner is a simple Java-based application designed to help students organize their studies and manage their time effectively. It allows students to plan subjects, create study tasks, set priorities, and keep track of their progress.

The main goal of this project is to make studying more organized and less stressful by providing students with a clear study plan in one place.

##  Features

* Add and manage subjects
* Create daily study tasks
* Set task priorities
* Track completed and pending tasks
* Organize study schedules
* Simple and easy-to-use interface

##  Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* **Git & GitHub**

##  How to Run the Project

### 1. Install Java

Make sure Java JDK is installed on your computer.

Check the installation using:

```bash
java -version
```

### 2. Clone the Repository

```bash
git clone <your-github-repository-link>
```

### 3. Open the Project

Open the project folder in any Java-supported IDE such as **IntelliJ IDEA, Eclipse, or VS Code**.

### 4. Compile the Project

```bash
javac Main.java
```

### 5. Run the Project

```bash
java Main
```

Follow the instructions shown by the application.
